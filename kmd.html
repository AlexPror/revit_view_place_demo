NORDFOX → Листы КМД

Команда «Листы КМД»

Одна кнопка: лист модуля, лист панели, листы профилей. Ниже — выпуск и что проверить вручную после него.

Шаг 3 · выпуск

Выпуск листов

Команда на ленте: NORDFOX → Листы КМД.

  1. Откройте фасад, с которого смотрите модуль (лицо панели на вас).
  2. Выберите сценарий: лист модуля, лист панели или листы профилей.
  3. Укажите один модуль на фасаде.
  4. Проверьте шаблоны (подставляются по именам), формат листа, масштаб и глубину в основание.
  5. При повторном запуске на том же модуле: заменить комплект или создать новый.

Лист модуля (В9 / В20)

  • Фасад, вертикальные и горизонтальные разрезы, рама, изометрия
  • Число разрезов ≈ число стоек и уровней ригелей
  • Типовой и угловой модуль

Лист панели (В10 / В21)

  • Спереди и сзади, разрезы, изометрия
  • Только панель (рама на лист не попадает)
  • Не заменяет уже созданный лист модуля

Листы профилей (В11–В12 / В22–В25)

  • Стойки и ригели крупным планом
  • Обрезка вида по эталону
  • Угловые модули — раскладка по эталонам В22–В25

Параметры в диалоге

  • Формат листа (A4…A0)
  • Масштаб видов
  • Глубина разреза в основание, мм

Видео: выпуск видов и листов

Выбор модуля → сценарий → лист по эталону.

Шаг 6 · после выпуска

Контроль качества

Надстройка собирает состав и раскладку; эталонный вид доводят в Revit.

  1. Масштаб видов совпадает с выбранным в диалоге.
  2. Виды не выходят за ячейку листа — при необходимости сдвинуть на листе.
  3. Лишние маркеры разрезов — отключить в видимости аннотаций.
  4. Подписи 1-1, 2-2… — проставить вручную при необходимости.
  5. На листах профилей — проверить крайние стойки и верхний / нижний ригель.
Анализ проекта

Отдельные кнопки на панели Анализ — см. три команды анализа. CSV пишется в Документы\NORDFOX\RevitViewPlace\exports.

Опорные плоскости

Для листов достаточно пары profil vertikalnyi centr (на стойке) + profil gorizontalnyi centr (на раме/модуле). Без них листы всё равно выходят по геометрии. Для профилей буквы и номера в имени обычно не нужны.

Как читать имя плоскости

Формат: группа → при необходимости тип → при необходимости номер → роль.

Тип — любое слово, которое не является числом: буква A, слово M16. Каждая такая подпись — свой тип в списке «Тип» диалога размеров.

Номер — только цифры (1, 2…). Порядок деталей в семействе, не отдельный тип и не фильтр в диалоге.

Примеры: zakladnaya top · zacep A top · shpora 1 gorizontalnyi centr · petlya M16 2 top.

Плагин смотрит имя плоскости, а не имя семейства Revit. Группы деталей КМД: закладные, шпоры, зацепы, профили, икли, соединители, петли.

Соответствие: UI ↔ префикс

В команде размеров выбираете группу — ищутся плоскости с тем же префиксом. Пункт Все детали берёт сразу все префиксы ниже (кроме профиля) в одну цепь вместе с краями оболочки.

zakladnaya · shpora · zacep · iklya · soedinitel · petlya · отдельно profil

Новая деталь с уже существующим префиксом не требует пересборки плагина. Новый префикс в имени — только после обновления надстройки с новой группой в UI.

Тип и номер в имени — когда нужны

Что в имениЭтоВлияние на цепь
zakladnaya top Только группа + роль Одна общая цепь группы на выбранной стороне.
zakladnaya 1 top, zakladnaya 2 top Номер — визуальный порядок одинаковых деталей Не отделяет цепи. При типе «все» в одну цепь попадут и 1, и 2.
zacep A top и zacep M16 top Тип — буква или слово Разные типы → две строки в поле «Тип» и две разные цепи.
shpora A 1 top Тип + номер вместе Цепь фильтруется по типу; цифра отличает экземпляры внутри типа.

Важно

Семейства «друг друга не изолируют». На виде в цепь попадают все экземпляры с подходящим именем плоскости. Разделяют цепи: сторона вида, группа, и при необходимости тип в имени + выбор типа в диалоге — не имя семейства и не один только номер.

Для профилей на листах достаточно центровых плоскостей без букв и номеров. TypeTag у профиля — только если на одном виде отдельно меряете разные сечения одной командой размеров.

Примечание: одно семейство профиля или два

Одно семейство — в ведомости одна строка на тип сечения. Стойка или ригель определяются при выпуске листов по плоскости и ориентации.

Два семейства — учёт одного проката дублируется. На скорость выпуска листов это не влияет.

Риски двух семейств: исполнитель может поставить «стойку» из семейства ригеля (или наоборот) — ошибка не видна до выпуска чертежей и спецификации; две номенклатуры на один прокат усложняют закупку и контроль остатков; при смене сечения правки нужно повторять в обоих семействах.

Правила загрузки семейств
  • После правок: «Загрузить в проект» → «Перезаписать» по всей цепочке вложенных семейств.
  • «Является ссылкой» = Сильная на рабочих плоскостях.
Как находятся стойки и ригели без плоскостей
  1. Сначала — именованные плоскости (если есть).
  2. Иначе — по габариту: стойка высокая и узкая; ригель длинный и низкий.
  3. Если и того нет — запасной набор разрезов по габариту модуля.

Шаг 4 · после листов

Цепочки размеров КМД

Отдельная команда на панели Правка видов. Работает на открытом виде модуля (не на листе). Нужны именованные плоскости в семействах. В группе можно выбрать одну деталь или Все детали (оболочка + закладные/шпоры/зацепы/икли/соединители/петли в одной цепи). Профили — отдельно. См. опорные плоскости.

  1. Откройте вид модуля (спереди / сбоку / сверху).
  2. NORDFOX → Правка видов → Цепочка размеров.
  3. Выберите режим: края, центры или от базы.
  4. Укажите базовый элемент и сторону вида.
  5. При необходимости ограничьте тип детали (если в именах плоскостей задан тип).

Видео: цепочки размеров

База → центры деталей на виде модуля.

NORDFOX → Правка видов → Ориентация видов

Команда «Ориентация видов»

Поворот кадра без пересборки листа. Не путать с выпуском листов и с цепочками размеров.

Шаг 5 · при смене фасада

Ориентация видов

Крест стрелок и угол из списка (90° по умолчанию, также 180° и 270°). Лист не пересоздаётся. Работает на видах комплекта плагина и на обычных видах / эталонах Revit.

  1. Выберите видовой экран на листе или откройте вид (разрез, фасад, 3д).
  2. NORDFOX → Ориентация видов.
  3. Выберите угол, нажмите стрелку направления поворота.

Два режима

Вид комплекта плагина — после поворота обновляется изоляция и подписи по роли вида.

Обычный / эталонный вид — только поворот кадра, без изоляции плагина (чтобы не скрыть геометрию эталона).

Ручные виды, разрезы и размеры Revit по-прежнему доступны; команда их не отключает.

Видео: смена ориентации

Стрелки и угол 90 / 180 / 270°.

NORDFOX → Правка видов → Вид по стороне

Команда «Вид по стороне»

Новый разрез. Исходный вид не удаляется. Планы и 3д не поддерживаются.

Правка видов

Вид по стороне

Клик у края открытого разреза или фасада создаёт вид с этой стороны. Клик в середине кадра — вид сзади.

  1. Откройте разрез / фасад или выберите viewport разреза на листе.
  2. NORDFOX → Правка видов → Вид по стороне.
  3. Кликните у левого, правого, верхнего или нижнего края кадра. Середина — сзади.

Что получится

Новый вид. На виде комплекта плагина сохраняется роль и изоляция. Появляется подпись масштаба «М 1:N».

NORDFOX → Правка видов → Глубина разреза

Команда «Глубина разреза»

Сдвиг near/far clip выбранного разреза в миллиметрах. Удобно, если на профиле обрезаны закладные.

Правка видов

Глубина разреза

Окно не блокирует Revit. Шаг задаётся в форме. «Обновить цель» — если сменили viewport.

  1. Выберите viewport разреза на листе или откройте разрез.
  2. NORDFOX → Правка видов → Глубина разреза.
  3. Дальняя плоскость: «Дальше» / «Ближе» — сколько модели видно вглубь.
  4. Ближняя плоскость: «Больше сзади» / «Меньше сзади» — срез позади камеры.

NORDFOX → Правка видов → Масштаб вида

Команда «Масштаб вида»

Чертёжный масштаб 1:N у выбранного вида, как у viewport на листе. Это не SCALE объектов модели.

Правка видов

Масштаб вида

После смены масштаба обновляется кадр и подпись «М 1:N» (ГОСТ 2.305). Шаблон вида не должен затереть выбранный 1:N.

  1. Выберите viewport на листе или откройте вид.
  2. NORDFOX → Правка видов → Масштаб вида.
  3. Укажите знаменатель N, нажмите Применить.

NORDFOX → Правка видов → Скрыть детали

Команда «Скрыть детали»

Закладные, икли, крепёж и соединители на виде: скрыть висящие или вернуть ранее скрытые.

Правка видов

Скрыть детали

Окно группирует детали. «Выбрать висящие» отмечает то, что не лежит на геометрии профиля. «Скрыть» / «Показать» работают по галочкам в списке.

  1. Откройте разрез или фасад либо выберите viewport на листе.
  2. NORDFOX → Правка видов → Скрыть детали.
  3. При необходимости: Только висящие, Только скрытые, Включать скрытые.
  4. Скрыть все висящие или отметьте строки и Скрыть. Показать скрытые возвращает скрытое этой командой.

NORDFOX → Оформление

Панель «Оформление»

Знак ориентации панели на листе. Кнопки выносок на узлах (полки с текстом из FSD) лежат на этой же панели и описаны в отдельном блоке ниже.

Оформление

Знак ориентации

Условный знак панели (круг, перекрестье, три планки) в левом верхнем углу листа. На листе панели ставится и автоматически при выпуске. Replace видов листа модуля и профилей этот знак не плодит.

  1. Откройте лист панели (или другой лист, куда нужен знак).
  2. NORDFOX → Оформление → Знак ориентации.

NORDFOX → Оформление → Выноски на узлах · Палитра выносок

Выноски на узлах

Плагин ставит на лист узла семейство «Выноска» (полка с текстом и стрелка к детали), берёт текст из FSD_Артикул и FSD_Примечание и сам подбирает ширину полки под текст. Положение полок и стрелок проектировщик при необходимости дорабатывает руками.

Выноски · обзор

Что делает и две кнопки

Семейство «Выноска» (категория «Типовые аннотации», тип «Выноска») лежит на листе, не на разрезе. Острие стрелки ставится у детали активного вида узла, полка — у кромки рамки вида на листе. Не путать со Знаком ориентации и с семейством «Выноска. узлы» (номер узла на схеме): эта команда его не трогает.

Кнопка на лентеЧто делаетКогда нужна
Выноски на узлах Ставит недостающие выноски на активном виде узла одной командой, без окна. Первая расстановка на узле.
Палитра выносок Окно, которое остаётся открытым: раскладка по сторонам, отступ, шаг, «Обновить тексты», «Поставить выбранные», список деталей с галочками. Выбрать, что ставить; поменять сторону; пересобрать тексты после правки FSD.

Выноски · подготовка

Что должно быть готово до запуска

  1. Вид узла стоит на листе (viewport). Плагин работает с активным видом: разрез, фрагмент, фасад, план или 3D узла. Если вид не на листе, палитра покажет «не на листе».
  2. На компонентах заполнены FSD_Артикул и FSD_Примечание (на типе или экземпляре). Живой связи с элементом нет: плагин копирует значения в момент постановки.
  3. В проекте есть семейство «Выноска» с параметрами текст, Двустрочный, Рзм_выноски, Рзм_кратность и формулой Ширина = Рзм_выноски * Рзм_кратность + Рзм_кратность. Без этих параметров ширина полки не подберётся.
  4. Нужны ступени 4 и 5 (50 и 60 мм)? Семейство должно содержать для них метки и параметры Да/Нет (как добавить), а на компьютере проектировщика должен лежать файл Документы\NORDFOX\RevitViewPlace\callout_steps.txt с числом 5. Без файла плагин пишет только ступени 1–3 (до 40 мм) и работает с любым семейством.

Выноски · порядок работы

Как поставить выноски

  1. Откройте лист узла. Двойной клик по viewport — активируйте вид узла.
  2. NORDFOX → Оформление → Выноски на узлах (быстро) или Палитра выносок (с выбором и раскладкой).
  3. Перед постановкой плагин заполняет пустые FSD на типах из встроенного каталога 1С, если имя типа уверенно совпало с артикулом. Уже заполненное не затирается.
  4. Для каждой подходящей детали (одна выноска на тип) ставится полка: текст, двустрочность, ступень ширины, стрелка к детали.
  5. Прочитайте отчёт: сколько поставлено, что пропущено (нет FSD, нет совпадения в каталоге), какие строки не влезли в самую широкую ступень.
  6. При необходимости подвиньте полки и концы стрелок руками. Положение и стрелки — зона проектировщика.

Область и дубли

Область — весь активный вид, включая вложенные детали. Хосты-сборки с вложенными компонентами и «модуль» пропускаются.

Одна полка на тип: одинаковые экземпляры не дублируются, уже стоящие (в том числе вручную) не повторяются рядом.

Нет FSD и нет уверенного совпадения в каталоге — полка не ставится, причина пишется в отчёт и в лог.

Выноски · палитра

Палитра выносок

Окно можно держать открытым рядом с листом. Заголовок показывает активный вид: Вид: «…» → лист N. Если вид не на листе или активен сам лист, кнопки не работают, окно просит активировать вид узла.

ЭлементЧто делает

Отступ от вида, ммРасстояние от кромки viewport до полки: 4–40, по умолчанию 8.

Выноски · текст

Откуда берётся текст и что плагин не трогает

  • Если заполнены оба поля — две строки: FSD_Артикул сверху, FSD_Примечание снизу, Двустрочный = Да. Если одно — одна строка. Больше двух строк не бывает.
  • Порядок монтажа и числа в скобках плагин не придумывает. Если проектировщик дописал текст вручную, при «Обновить тексты» он остаётся.
  • В поле Comments выноски плагин хранит метки NF_src_type (тип детали) и NF_auto (текст, который поставил сам). «Обновить тексты» переписывает полку только если её текст всё ещё равен NF_auto.
  • Ручной текст не затирается. Чтобы вернуть автотекст, очистите поле текст или удалите выноску и поставьте заново.
  • Автообновления нет. После смены FSD или модели нажмите «Обновить тексты» или «Поставить выбранные».
  • Детали, представленные только импортированной DWG-геометрией (например, дюбель), автоматически не определяются: такие выноски ставятся вручную тем же семейством.

Выноски · ширина полки

Ширина полки: ступени Рзм_выноски

Плагин сам пишет два параметра выноски: Рзм_выноски (ступень) и Рзм_кратность (плечо, 10 мм). Ширину считает формула семейства: Ширина = Рзм_выноски × Рзм_кратность + Рзм_кратность. Вручную ширину задавать не нужно.

Рзм_выноскиШирина при Рзм_кратность = 10Параметр Да/НетПример текста
120 мм20«Профиль L15», «Профиль Н21», «Бокс 50х50х2»
230 мм30«Термомост ISO L», «Термомост ISO ML»
340 мм40«Кронштейн UFOX 270L»
450 мм50«Шайба распределительная»
560 мм60«Удлинитель кронштейна UDFB 160.3Z»
  1. Плагин измеряет самую длинную строку текста тем шрифтом, которым она будет напечатана (3 мм, с поправкой на ширину метки семейства).
  2. Берёт минимальную ступень, у которой ширина не меньше измеренной.
  3. Записывает Рзм_выноски и Рзм_кратность = 10. Параметры Да/Нет и Сдвиг_текста семейство переключает формулами само.
  4. Если строка длиннее самой широкой доступной ступени, плагин ставит эту ступень и пишет предупреждение: строка шире ступени: «…» нужно N мм, стоит Рзм_выноски=R (W мм). Полка не остаётся пустой.

Почему плечо всегда 10 мм

Рзм_кратность — не только множитель ширины, но и длина короткого плеча графики семейства, на которое стыкуется линия выноски. Если уменьшить её (например, до 7 мм), между полкой и линией появляется видимый разрыв. Поэтому плагин не ужимает плечо под текст, а набирает ширину ступенями.

Если текст не влез в 60 мм, сократите FSD_Примечание или вручную увеличьте Рзм_кратность этой выноски (12–15): плечо станет длиннее, разрыва не будет. Это значение рассчитано на одну выноску: при пересчёте ступени («Обновить тексты») плагин может вернуть 10.

Выноски · семейство

Как добавить ступень в семейство «Выноска»

Делается один раз в шаблоне семейства, не плагином. Плагин ступени 4–5 включит, только когда семейство их умеет.

  1. Откройте семейство «Выноска» (Редактировать семейство) или файл Выноска.rfa.
  2. Добавьте параметр экземпляра типа Да/Нет, группа «Прочее»: 50 (затем 60). Имя — по образцу 20/30/40.
  3. Задайте формулу по образцу соседней ступени: для 50 — Рзм_выноски = 4, для 60 — Рзм_выноски = 5.
  4. Скопируйте метку (Label) предыдущей ступени и растяните рамку по ширине ступени. У новой метки параметр метки — текст (не новый параметр), в свойстве Видимость — новый Да/Нет.
  5. Загрузите семейство в проект: Загрузить в проект и выберите «Заменить существующую версию и значения параметров».
  6. Положите файл Документы\NORDFOX\RevitViewPlace\callout_steps.txt с числом 5 (или 4) и перезапустите Revit.

Важно

Голая ступень 4 без метки: Рзм_выноски = 4 уже меняет ширину, но, если метки нет, текст на листе пропадает. Поэтому плагин по умолчанию не пишет ступени выше 3.

Формула Ширина в семействе не снимается. Если её убрали, плагин при запуске восстанавливает формулу сам; 120 мм и другие жёсткие значения он не пишет.

Проект с рабочими наборами

Если проект — локальная копия центральной модели, «Сохранить» пишет только в локальный файл. Если закрыть Revit через «Закрыть локальный файл» без синхронизации, при следующем открытии центральной модели создастся новая локальная копия без правки семейства: параметры «пропали». Это поведение Revit, не плагина.

Перед закрытием: Совместная работа → Синхронизировать с центральным файлом (или в окне выхода «Синхронизировать с файлом хранилища»). Старая локальная копия остаётся рядом с суффиксом даты в имени.

Выноски · лог

Логи — в Документы\NORDFOX\RevitViewPlace\logs, первая строка файла содержит версию плагина. При вопросах присылайте файл целиком.
