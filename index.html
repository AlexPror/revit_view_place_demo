Листы КМД по эталонам

По выбранному модулю на фасаде формируются лист модуля, лист панели и листы профилей. Раскладка видов и шаблоны — как в эталонных чертежах проектного бюро.

Пилот принят — проверены типовой, угловой, горизонтальный, парапетный, узкий и внутренний угловой модули.

Комплектов по типам ~108
Вручную, один комплект 60–90 мин
С надстройкой, один комплект 10–15 мин
Модулей на фасадах 656

Эффект по времени

Считаем 108 комплектов — по одному эталону на каждый тип модуля. Повторяющиеся типы оформляются по одной схеме; в сравнении участвуют типы, а не каждый модуль на фасаде отдельно.

Один комплект — лист модуля, лист панели, листы профилей, цепочки размеров и при необходимости поворот вида под другой фасад.

Возможности

Лист модуля (В9 / В20)

  • Фасад, разрезы по стойкам и ригелям, рама, изометрия
  • Типовой и угловой модуль

Лист панели (В10 / В21)

  • Виды оболочки спереди и сзади, разрезы
  • Оформляется отдельно и не заменяет лист модуля

Листы профилей (В11–В12 / В22–В25)

  • Выделение стоек и ригелей, обрезка вида по эталону
  • Для угловых модулей — раскладка по эталонным листам В22–В25

Цепочки размеров

  • От базовой линии до центров деталей по выбранной стороне вида
  • Выполняется отдельной командой, после выпуска листов

Ориентация видов

  • Поворот одного вида на 90° или 180° без пересборки листа
  • Для модулей на других фасадах — без повторной настройки разрезов и скрытий

Опорные плоскости

Одно семейство профиля для стойки и ригеля. Роль детали определяется расположением плоскости в модуле и её ориентацией.

ПлоскостьГде задаётсяНазначение
profil vertikalnyi centr профиль (вложенный) Вертикальный разрез → стойка, если плоскость перпендикулярна ширине модуля
profil gorizontalnyi centr рама / модуль Уровень ригеля → высота горизонтального разреза
Одно семейство профиля или два

Одно семейство — в ведомости одна строка на тип сечения (H20, H21…). Стойка или ригель определяются при выпуске листов.

Два семейства — учёт одного проката дублируется, контроль усложняется. На скорость выпуска листов это не влияет.
